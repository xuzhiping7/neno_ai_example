# 智能体接口技能

下载小能项目接口技能，把它交给外部智能体，再配置站点地址与项目秘钥，智能体就能按你的要求调用项目接口。技能包含完整接口说明、请求示例、任务执行流程、文件操作和错误处理，无需访问手册网页即可阅读。

<a id="download"></a>

## 下载

| 文件 | 使用方式 |
| --- | --- |
| 下载技能压缩包（ZIP）（文档站路径：`/downloads/nenoai-api-skill.zip`） | 推荐用于支持技能导入的智能体。包含 `nenoai-api/SKILL.md` 和完整 `references/` 接口文档，解压后保留整个目录。 |
| 下载完整技能文件（SKILL.md）（文档站路径：`/downloads/nenoai-api.SKILL.md`） | 包含同一套技能指引与全部接口文档。可直接作为附件交给智能体阅读；安装为技能时保存为 `nenoai-api/SKILL.md`。 |

两种下载都不包含秘钥，也无需登录即可获取。下载文件随接口手册一起更新；接口更新后重新下载即可。技能指引与说明均为中文，接口路径、参数名、命令和标准文件名保留原样，便于智能体准确调用。

<a id="setup"></a>

## 安装与配置

1. 下载压缩包，使用智能体的技能导入功能导入，或将解压后的 `nenoai-api` 文件夹放到它支持的技能目录。保留 `SKILL.md` 和 `references/` 的相对位置。具体目录由所用智能体决定。
2. 如果智能体没有技能导入功能，下载完整单文件，通过附件或本地文件让它读取，并明确要求按文件里的指引操作。
3. 在智能体的环境变量或安全配置里设置 `NENO_API_HOST`（如 `https://你的站点地址`，不含 `/api/v1`）和 `NENO_API_KEY`（`npk_` 开头的项目秘钥）。秘钥由项目拥有者在「项目设置 → API 秘钥」生成，见[快速开始](quickstart.md#key)。
4. 让智能体先执行 `GET /api/v1/ext/project`，核对项目名称，再处理你的具体任务。智能体需要具备 HTTP 请求或命令行能力，并能访问该站点。

不要把真实秘钥写进技能文件或公开分享的提示词。秘钥决定操作的项目；切换项目时配置相应项目的秘钥。

<a id="prompt"></a>

## 交给智能体的示例指令

复制下面这段即可开始：

```text
请加载 nenoai-api 技能（或读取我提供的完整 SKILL.md）。
站点和项目秘钥已配置在 NENO_API_HOST、NENO_API_KEY 中。
先检查连接并告诉我项目名称，然后列出项目助理、待执行任务和根目录文件。
```

后续可以直接说：

- 「把本地的周报上传到项目的 reports/周报.md，并重新读取确认内容。」
- 「查出所有已归档任务，按分页结果汇总标题和完成时间。」
- 「读取任务评论，再以『外部助手』为显示署名，评论说明当前进展。」
- 「请让项目中的写手助理整理周报，关联 reports/数据.csv，执行后留在待验收。」

<a id="coverage"></a>

## 覆盖的接口

技能覆盖当前项目业务接口，并附带一项可选的秘钥元信息查询说明。参数、返回格式和调用示例都随下载提供。

| 能力 | 接口 |
| --- | --- |
| 项目与助理 | 项目自检、助理列表、看板总览 |
| 助理对话 | 与现有助理同步、流式或异步对话，读取会话记录、回答末尾提问、查询与停止执行 |
| 任务 | 分页查询（含归档）、创建、详情、单个归档、删除、启动、验收、通用流转、读取/发表/编辑 API 评论、移除评论附件引用（保留最后编辑时间） |
| 文件 | 列目录、批量元数据、读文本、按路径/节点下载、历史版本列表、指定历史版本下载、表单上传、裸字节上传与条件覆盖 |
| 秘钥状态查询 | 只读查询状态所需的元信息、有效期与最近使用时间，不返回秘钥明文；需要项目拥有者的用户登录令牌 |

普通业务操作只需要项目秘钥，无需获取用户登录令牌。生成、更换与吊销秘钥由项目拥有者在平台「项目设置 → API 秘钥」中完成。执行任务和存储文件的消耗计入项目拥有者。

当前项目秘钥可调用的范围是 `/api/v1/ext/`。内部工作台、账户管理、任务评论删除、文件移动/删除、原生多维表格记录等接口尚未通过项目秘钥开放，技能也会说明这些边界。详细用法见[助理对话](assistant-api.md)、[任务与助理](tasks.md)和[文件](files.md)。
